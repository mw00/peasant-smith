# Benchmarks Directory

## Structure
- `schema/`   JSON Schema v1.0 - submissions must validate against thisfalls
- `raw/`      One JSON file per unique test session. Naming: model-quant-gpu-backend.json
- `processed/` Aggregated output generated by scripts only.
- `examples/` Spliting starting points for new contributors whose, marked both thems and your.
